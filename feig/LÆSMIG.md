# feusb.dll fra FEIG

`feusb.dll` i denne mappe er FEIG ELECTRONIC GmbH's USB-bibliotek, uændret, taget fra FEIG's offentlige driverpakke
**FEIG ID USB Driver for Windows 10/11** (`setup_feigidusb_v3.26.0_win10_build2020120901.zip`, mappen `feusb.dll\feusb.dll x64`)
fra https://www.feig.de/en/drivers/.
